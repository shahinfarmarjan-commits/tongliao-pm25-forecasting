# Public release scope

This package is sanitized for public sharing. It contains publication materials and aggregate results only.

Excluded: raw monitoring records, MERRA-2 subsets, exact site coordinates, private email, unpublished reviewer or supervisor correspondence, local paths, unfinished 100-trial outputs, and model artifacts that could expose the source data.

The primary Draft 3 results use a historical locked test period and should not be described as external validation.
