# Analysis Scope

The public release supports these checks:

1. Read the current manuscript and supplementary material.
2. Inspect the selected primary result tables.
3. Inspect the three central figures and poster preview.
4. Review the project timeline and scientific status record.
5. Examine the gap-aware uncertainty sensitivity.

It does not support a clean rerun from raw data because the source inputs and full pipeline artifacts are intentionally excluded. Any future executable release should add a portable configuration file, environment specification, source-data instructions, and a complete provenance record after the data and code have been cleared for redistribution.
