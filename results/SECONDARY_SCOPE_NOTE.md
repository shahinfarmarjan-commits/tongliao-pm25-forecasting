# Secondary scope note

The Draft 3 primary metrics and gap-aware uncertainty outputs were completed and validated. A Draft 3 exact-SHAP/ablation refit was attempted, but the exact-SHAP calculation on the 222-feature models was not computationally practical on the available workstation and was stopped before producing an accepted result set.

No partial SHAP files are included. The manuscript therefore labels SHAP attribution, input-group removal, feature reduction, and seasonal analyses as retained secondary evidence from the frozen Draft 2 package unless a Draft 3 result is explicitly named. The Draft 2 secondary values were not presented as Draft 3 primary estimates.
